# navileshbhatti.xyz

Static portfolio. No build step.

- `index.html`, `404.html`, `admin.html` (private inbox, noindex)
- `css/` styles, `js/` ES modules (`config.js` holds environment config, `firebase.js` data access, `ui.js` / `consent.js` / `contact.js` features)
- `img/` icons and social image, `CNAME` custom domain, `_headers` security headers for hosts that support it

Deploy: push to the repo root (GitHub Pages) with the domain set to navileshbhatti.xyz.
After deploying, add navileshbhatti.xyz under Firebase Console > Authentication > Settings > Authorized domains so admin login works.

## Project images
Replace the blank canvases by overwriting files in img/projects/ (same file names, 1280x720 WebP): arkenfold, klyro, gravity-drift, fixflow, video-editor.
